Department timetable builder

Set up your classes and teachers, enter how many hours each teacher takes in each class, and generate a clash-free timetable.

Department Preset

Select a department to load its teachers and automatically divide teaching hours (16 hrs per teacher, remainder to last).

Teachers

Short form is a 3–8 letter code (auto-filled, editable) used on compact timetables and the master schedule. The subject shows up in each timetable cell. Max per day caps how many periods a teacher can be given on a single day. Assigned total hours can be edited directly.

The week

Days in the week and the most periods any class can have in one day. Periods are the same time slots for every class, so a teacher is never booked in two places at once.

Classes

Enter how many hours each class has on each day — the row total is its weekly hours. Use Max/t/day to strictly limit how many hours any single teacher can take in this class per day. For a class that doesn't run all day, use Choose to pin the exact periods it meets.

Teacher exceptions in classes

Override the daily limit for a specific teacher in a specific class (e.g. allow a teacher with 8 hours in a class to take up to 2 hours per day, while keeping others in that class at max 1).

Start over

Reset everything back to the example department: 7 classes, 8 teachers, five 5-period days.

Hours per teacher, per class

Each cell is the number of periods that teacher takes in that class every week. A column has to add up to the class's weekly hours before a timetable can be built.

Fairness & optimization

Locked hours

Click any cell in a generated class timetable to lock that teacher into that period. Locked hours stay put when you generate again — everything else is rebuilt around them.

Department Hours

Enter total weekly teaching hours. Hours are divided so the first teachers receive 16 hours each and the last teacher receives the remainder. All hours are editable.

Share Timetable Setup

Send this link to anyone. When they open it, your entire timetable configuration — classes, teachers, assigned hours, and rules — will load automatically so they can continue working.
